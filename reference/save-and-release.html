Saves and release

A compact aid to use after attempting retrieval. This sheet does not certify that these concepts are learned.

State inventory

A coherent snapshot captures one tick’s relevant cells, counters, metadata, weather deltas, cooldowns, falling groups and the agreed particle policy. Scheduler remainder persistence is a decision to document.

Crash consistency

One writer orders disk operations. Per-file replacement is not a transaction spanning many files. A committed manifest/generation policy must let loading select a complete old or new snapshot.

Versions

Format version controls decoding. Generator version controls how absent terrain regenerates. Keep old supported fixtures; reject unsupported data without modifying the input world.

Release artifacts

cargo build --release builds optimized executables. cargo package creates a source crate archive, not an end-user game installer. Package assets and licences explicitly and test native launches outside the checkout.

Retrieve before reading

Interrupt a simulated save after one region file completes but before the manifest commits. Demonstrate why loading still chooses a coherent prior generation.
