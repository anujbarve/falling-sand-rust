Grid and storage

A compact aid to use after attempting retrieval. This sheet does not certify that these concepts are learned.

Coordinate contract

The first prototype counts rows downward. Production world altitude increases upward. Use an explicit conversion. One simulation cell occupies 2 × 2 art pixels and 4 × 4 physical pixels.

Index contract

Validate signed coordinates before conversion. Row-major flat index is row * width + column. Invalid coordinates return None; index zero is a valid cell, not a missing-cell sentinel.

Chunk contract

A chunk contains 64 × 64 cells. Euclidean quotient identifies the containing chunk and Euclidean remainder identifies a nonnegative local coordinate, including for negative world positions.

Update contract

Moving matter must clear or swap its source. Scan order and moved markers prevent repeated movement. Clip updates per cell to the active rectangle, not merely per overlapping chunk.

Retrieve before reading

For world x = -1 and a chunk width of 64, calculate the chunk x and local x. Then test x = 0, 63 and 64 and verify a round trip.
