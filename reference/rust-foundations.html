Rust foundations

A compact aid to use after attempting retrieval. This sheet does not certify that these concepts are learned.

The edit/run loop

Work inside game/. cargo check checks compilation; cargo run builds and launches; cargo fmt formats source; cargo test runs tests. Formatting is not behavioral verification.

Bindings and functions

Use let for a binding, let mut for a binding you reassign. Integer cell coordinates and floating-point drawing/time values have different units. A function’s final expression can supply its return value.

Ownership and access

By-value arguments move non-Copy values. &T borrows shared access; &mut T borrows exclusive mutable access while used. A borrow may end at its last use, not necessarily the enclosing closing brace.

Modeling state

Use structs for named fields, enums for valid alternatives, Option for possible absence and Result for recoverable failure. Match the alternatives instead of assuming every operation succeeds.

Retrieve before reading

From memory, write a function that changes one borrowed Cell and another that only reads it. Compile both, then deliberately try a mutation through the shared reference.
