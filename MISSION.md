# Mission: learn Rust by building a calm ecological sandbox

## Why
Learn Rust from the beginning by personally building the ecological sandbox described in the game-design and art-style specs. Each short module should add a visible, understandable piece of the eventual game, culminating in a house on a hillside weathering through rain, fire and seasons, followed by a releasable game.

## Success looks like
- Explain, modify and debug the Rust used in each completed feature without relying on a pasted solution.
- Build and verify the M0–M7 milestones, including their behavior, visual and target-hardware acceptance checks.
- Prepare runnable Mac, Windows and Linux packages with recoverable saves, clear controls and recorded release evidence.

## Constraints
- Start from zero Rust knowledge; other programming and terminal experience has not yet been established.
- Keep each module focused on one outcome, with in-depth explanation, worked code/commands, diagrams, exercises, troubleshooting and feedback suitable for a YouTube series.
- Use Matt Pocock's installed teach skill for the HTML course, with the workspace's teach process during live tutoring.
- Keep the game and art specs authoritative; unresolved decisions and hardware claims need evidence and approval.

## Out of scope
- Unrelated Rust survey topics that are not needed for this game.
- Implementing the full game on the learner's behalf, or treating drafted lessons as demonstrated knowledge.
- Publishing, pushing or distributing a release without an explicit request.
