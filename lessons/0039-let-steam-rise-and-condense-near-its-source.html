Let steam rise and condense near its source

Condensation occurs roughly 40–80 cells above formation when the active region contains that path. Camera clipping is reported separately.

Previously: Boil water and cool lava into basalt. Keep that working result available before starting this lesson.

Why we need this now

Previously a camera-relative cloud band made steam condense at different world locations when the observer moved. The fix is not “draw the band higher.” Steam must carry its own temperature and cool through the same local update wherever it exists. The camera chooses whether it is active, not its thermodynamic rule.

Your result: Condensation occurs roughly 40–80 cells above formation when the active region contains that path. Camera clipping is reported separately.

01Store the moving state with the gas

A Steam cell contains temperature just like other non-air materials. When movement swaps it with air, that temperature travels with it. Cooling therefore belongs to the cell update, not a screen row. If you leave temperature in the old grid position while moving only the material id, the gas seems to forget its heat and the newly exposed air inherits meaningless state. Move the complete Cell value or explicitly transfer all relevant fields.

02Tune distance from rate and lifetime

Suppose the gas rises two cells per tick. Condensing after about 20–40 ticks gives an undisturbed travel distance around 40–80 cells. A simple lab subtracts a fixed amount of temperature each tick until a threshold is reached. Production cooling toward local ambient may depend on conditions, so “roughly fixed” is a tuning target, not a theorem. Record source temperature, ambient value, rise rule and threshold whenever measuring the distance.

03Respect obstacles and the active margin

A roof can block upward motion while the trapped gas continues cooling. That means condensation may happen close to its source rather than at the open-air target distance, which is sensible for the local rule. If the active boundary absorbs steam first, credit weather humidity according to the design and report it as boundary absorption. Do not pretend an off-screen deletion proves that condensation occurred. The camera-independence test must compare a shared active interior with enough space for the full path.

04Use a controlled trace before the full scene

Start one steam parcel at a known temperature and altitude. Each tick record temperature and altitude; stop on conversion. This gives a table that can be narrated on video: state before, cooling, rise, state after. Repeat with the source translated upward by 100 cells while keeping ambient fixed. The number of updates should stay the same. Then restore ambient altitude dependence and explain any changed result as climate, not camera behavior.

fn condensation_distance(mut temperature: i16, threshold: i16) -> i32 {
    let mut height = 0;
    while temperature >= threshold {
        temperature -= 2;
        height += 2;
    }
    height
}
#[test]
fn cooling_sets_a_bounded_travel_distance() {
    assert_eq!(condensation_distance(130, 100), 32);
    assert_eq!(condensation_distance(150, 100), 52);
}

Exercises you actually do

01

Tune the low source

Make a 130°C source travel 40–80 cells under this fixed-cooling lab.

Need a hint?

Changing a cooling decrement changes the number of iterations.

Worked solution

A decrement of 1 with rise 2 produces 62 cells before crossing below 100. Recompute the other fixture too; tuning one source can affect the rest. In production, choose approved source initialization rather than arbitrary test-only temperatures.

How to verify your result

The measured low-source distance lies in the target range.

02

Translate the source

Add a source altitude argument and return the final altitude.

Need a hint?

Distance and absolute altitude are different outputs.

Worked solution

Return source_altitude + distance. Sources at 0 and 100 should finish 100 cells apart while travelling the same distance under identical cooling conditions.

How to verify your result

Translation preserves travel distance with fixed ambient.

03

Test a roof

What changes when the gas cannot rise after eight cells?

Need a hint?

Cooling continues even when movement is blocked.

Worked solution

Run the same per-tick temperature update but stop movement at the roof. Condensation occurs at a smaller travelled distance. The open-air distance target does not justify passing steam through solid cells.

How to verify your result

Blocked steam cools without tunnelling through the roof.

When it goes wrong

Start with the observed symptom. Change one assumption at a time instead of pasting fixes until the error disappears.

Panning changes condensation altitude

What is happening: Cooling or conversion reads screen coordinates.

Try this: Use world state and local ambient inputs only.

Steam never cools under a roof

What is happening: Cooling was placed only inside the successful-move branch.

Try this: Run thermal update independently of motion success.

The trace never terminates

What is happening: Cooling decrement is zero or wrong-signed.

Try this: Assert a positive cooling rate and bound test duration.

Explain it without the example

Why must camera-boundary absorption be tested separately from condensation?

Reasoning to compare

One removes gas at the active margin and credits humidity; the other transforms steam locally into water. Treating them as the same process hides camera effects.
