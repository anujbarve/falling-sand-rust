How this course works

Each lesson begins with a concrete problem from the game. Follow the explanation, predict the example, run it, then attempt the exercises. Worked solutions and troubleshooting are included so you can learn independently and bring specific questions to your tutor. Lessons include explained commands or code, expected results, worked exercises, troubleshooting. Later examples isolate one mechanism before you integrate it with the existing game.

The mission is to learn Rust while creating this calm sandbox. Work through each lesson at your own pace. At each milestone, agree on its implementation plan; unresolved spec decisions are explicit design labs. Learning records and the canonical glossary are written only after you demonstrate understanding.

The earlier five Markdown drafts are preserved as history. This HTML course is the active path and splits their work into smaller steps.

Reference shelf · Milestone coverage and remaining decisions · Trusted resources and optional communities

Local browser storage is optional; if unavailable the course still works. Marks are attempts, not grades. Revisit an earlier exercise on a later day before relying on recall.
